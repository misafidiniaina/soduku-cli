# Tetris

Tetris is selected from the root launcher and starts immediately.

## Controls

| Key               | Action                  |
| ----------------- | ----------------------- |
| `↑` / `W`         | Rotate the piece        |
| `←` `→` / `A` `D` | Move the piece          |
| `↓` / `S`         | Soft drop               |
| `Enter`           | Instant drop            |
| `p` / `Space`     | Pause or resume         |
| `r`               | Restart                 |
| `m`               | Return to the game menu |
| `q` / `Ctrl+C`    | Quit                    |

## Rules

Place tetrominoes to complete horizontal lines. Completed lines disappear and award points. The game becomes faster as the level increases. The game ends when a new piece cannot be placed.
