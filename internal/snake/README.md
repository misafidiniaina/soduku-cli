# Snake

Snake is selected from the root launcher and starts immediately.

## Controls

| Key                                | Action                  |
| ---------------------------------- | ----------------------- |
| `↑` `↓` `←` `→` or `W` `A` `S` `D` | Move the snake          |
| `p` / `Space`                      | Pause or resume         |
| `r`                                | Restart                 |
| `m`                                | Return to the game menu |
| `q` / `Ctrl+C`                     | Quit                    |

## Rules

Eat the food to grow and increase your score. The snake gets faster every five foods. Hitting a wall or the snake's body ends the game. The best score is kept across restarts during the current session.
